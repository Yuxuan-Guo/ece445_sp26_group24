## Project Overview

Group 24 is developing an **Antweight Battle Bot** for ECE 445 Senior Design. The project focuses on building a compact, safe, and controllable combat robot for the 2 lb antweight class.

The final system uses an ESP32-S3-based control board, Wi-Fi teleoperation, two Mini Brushed Mk2 planetary gearmotors, DRV8871-based motor drivers, a single front lifter/wedge mechanism, and a 3S LiPo battery power system. The design emphasizes reliable mobility, stable logic power, wireless control responsiveness, and safe shutdown behavior during manual kill-switch events, link loss, and fault conditions.

This repository is used to document team meetings, individual progress, design decisions, hardware development, software testing, mechanical integration, verification results, and reflections throughout the semester.

## Lab Notebook Purpose

The lab notebooks serve as a chronological record of our senior design work. Each entry documents the date, objectives, work completed, problems encountered, design changes, testing results, and next steps. Team meeting entries are shared between members when applicable, while individual entries describe each member’s specific contributions.
